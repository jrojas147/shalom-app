Cierre de mes

Defina un día sugerido (1 a 28) para revisar inventario, compras y ventas. El cierre se puede ejecutar cuando se requiera (semanal, quincenal o en cualquier momento); cada corte cubre desde el último cierre hasta ahora. Se limita a 28 para que el recordatorio exista todos los meses, incluido febrero.
